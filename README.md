# {username-kamu}-pabwe-p2 — Aksara.AI

Studi kasus Praktikum CSS & CSS Framework: website perusahaan jasa AI fiktif **Aksara.AI**.

## Struktur

- `index.html` — Landing page (HTML + CSS murni, external stylesheet di `assets/css/style.css`)
- `blog.html` — Daftar artikel blog AI (Bootstrap 5 + Bootstrap Icons)
- `blog-detail.html` — Detail satu artikel blog (Bootstrap 5 + Bootstrap Icons)
- `cv.html` — CV digital (Tailwind CSS 4, Play CDN)
- `assets/css/style.css` — Stylesheet khusus `index.html`
- `assets/img/` — Logo dan ilustrasi flat-design (dibuat sendiri, bukan hasil unduhan)

## Yang perlu kamu ganti sebelum dikumpulkan

- Ganti "Nama Anda", email, nomor WhatsApp, dan riwayat pendidikan/pengalaman di `cv.html`
  dengan data dirimu sendiri.
- Ganti nama file/folder proyek menjadi `{username-kamu}-pabwe-p2`.
- Opsional: ganti `assets/img/cv-avatar.png` dengan foto profil asli.

## Menjalankan

Buka `index.html` langsung di browser, atau gunakan ekstensi Live Server di VS Code.
Semua halaman saling terhubung lewat navbar (Landing Page ↔ Blog ↔ CV).
